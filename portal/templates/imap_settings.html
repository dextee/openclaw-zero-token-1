How to get a Gmail App Password

  1. Go to your Google Account → Security → 2-Step Verification (must be ON)
  2. Scroll down → App passwords
  3. Select app: Mail, device: Other → name it "Mirae outreach"
  4. Copy the 16-character password shown (spaces don't matter)
  5. Paste it below — you won't be able to see it again

For non-Gmail providers, use the correct IMAP server and port (Outlook: imap-mail.outlook.com / 993).
